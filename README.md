# Creating Virtual Machine In AWS

# 🎯 Project Overview

This project showcases the ability to provision an Amazon Machne Image Microsoft Windows Server 2025 in an AWS cloud environment, demonstrating practical cloud computing skills and administration knowledge.

## 🏗️ Architecture

**Cloud Provider**: Amazon Web Services (AWS)  
**Service**: Elastic Compute Cloud (EC2)    
**Region**: us-east-1

### Step 1: AWS Console Access

- Accessed EC2 service dashboard
- Prepared for instance creation

### Step 2: Selected AMI Image Type 
Selected Image Type: 
- Type: Microsoft Windows Server 2025
- Architecture: 64-bit (x86)

<img width="696" height="278" alt="Windowe" src="https://github.com/user-attachments/assets/edd5dbbc-fae4-4667-b95c-64bc29ca1be4" />

### Step 3: Instance Type Configuration
Selected the following Instance Type:

- Instance Type:     t3.xlarge
- vCPUs:            4
- Memory:           16 GiB

*The t3.xlarge instance type provides sufficient compute resources for Windows Server workloads while maintaining cost-effectiveness*.

### Step 4: Created Key Pair
Created new key pair for secure instance access via RDP authentication

- Key Pair Type: RSA 
- Format: .pem (for OpenSSH)
